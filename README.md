# studio-ch/homebrew-tap

Homebrew formulae for [Flow Swiss](https://cloud.flow.swiss) tools.

```bash
brew install studio-ch/tap/xcloud
```

`brew tap studio-ch/tap` resolves to this repository — Homebrew expands
the short form to `github.com/<user>/homebrew-<repo>`, which is why the
name carries the `homebrew-` prefix.

## Formulae

| Formula | Description |
|---|---|
| `xcloud` | Command-line interface for the Cloud Console — see [studio-ch/xcloud-cli](https://github.com/studio-ch/xcloud-cli) |

## About this repository

Everything under `Formula/` is **generated**. GoReleaser writes and
commits each formula as part of a release, so a formula here always
matches a published artifact and its checksum.

Do not edit formulae by hand: the next release overwrites them. Report
problems against the tool's own repository instead.
